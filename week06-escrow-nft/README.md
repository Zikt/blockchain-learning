# Week 06: Escrow and an on-chain NFT

**Dates:** 2 Nov – 8 Nov 2026 · **Planned time:** 10 h

**Goal:** Write your first contract that holds value, then an NFT whose image lives entirely on-chain. End with frontend prep for next week.

**Ship:** Project 3b (Escrow.sol) and Project 3c (on-chain SVG NFT)

### Plan

- [ ] Learn (45 min): Solidity docs: Security Considerations (read before writing code that holds money)  
  [Security considerations](https://docs.soliditylang.org/en/latest/security-considerations.html)
- [ ] Learn (45 min): Solidity by Example: Sending Ether, Payable, and the Re-entrancy hack  
  [solidity-by-example.org](https://solidity-by-example.org/)
- [ ] Build (180 min): Build Escrow: deposit, release by buyer or arbiter, refund after a deadline, dispute. Emit events, use checks-effects-interactions
- [ ] Write (30 min): Log: every state the escrow can be in, as a small state diagram
- [ ] Learn (30 min): Read EIP-721  
  [EIP-721](https://eips.ethereum.org/EIPS/eip-721)
- [ ] Learn (30 min): OpenZeppelin ERC-721 docs and the Wizard  
  [OpenZeppelin Contracts](https://docs.openzeppelin.com/contracts/) · [Wizard](https://wizard.openzeppelin.com/)
- [ ] Build (120 min): Build an NFT whose tokenURI returns base64 JSON with an SVG generated in Solidity
- [ ] Write (30 min): Log: what an NFT actually owns, and what lives off-chain in most NFTs
- [ ] Learn (45 min): viem: getting started, reading and writing contracts  
  [viem.sh](https://viem.sh/)
- [ ] Learn (45 min): Scaffold-ETH 2 docs: hooks and deploying  
  [docs.scaffoldeth.io](https://docs.scaffoldeth.io/) · [wagmi](https://wagmi.sh/)
